MATHQUEST SMP — KOMPETISI KELOMPOK 1–3
Mata kuliah: Pengantar Pendidikan

ISI FOLDER
- index.html       Aplikasi permainan dan papan peringkat realtime
- manifest.json    Metadata PWA
- sw.js            Cache shell aplikasi
- firestore.rules  Aturan keamanan database Firestore
- PETUNJUK.txt     Panduan setup Firebase dan hosting

SETUP FIREBASE
1. Buka https://console.firebase.google.com/ dan pilih proyek mathquest-97be3.
2. Authentication > Get started > Sign-in method > Anonymous > Enable > Save.
3. Firestore Database > Create database. Pilih Production mode dan lokasi terdekat yang tersedia.
4. Setelah database dibuat, buka tab Rules.
5. Ganti isi Rules dengan isi file firestore.rules, lalu klik Publish.
6. Pastikan aplikasi web sudah terdaftar dan konfigurasi di index.html sesuai proyek Firebase.
7. (Opsional untuk deploy) Pasang Firebase CLI di komputer, lalu jalankan:
   npm install -g firebase-tools
   firebase login
   firebase init hosting
   - pilih Use an existing project, lalu mathquest-97be3
   - public directory: . (titik)
   - configure as single-page app: No
   - overwrite index.html: No
   firebase deploy --only hosting
8. Buka URL Hosting yang diberikan Firebase dan bagikan URL yang sama kepada semua pemain.

CATATAN PENTING
- Internet diperlukan untuk login anonim, menyimpan hasil, dan melihat papan peringkat bersama.
- Permainan dan file shell dapat dicache setelah aplikasi dibuka saat online; kemampuan offline penuh bergantung pada cache browser dan tidak mengirim hasil ke cloud sampai online lagi.
- Hasil setiap percobaan disimpan sebagai entri. Papan peringkat menampilkan waktu tercepat; penentuan pemenang kelompok mengambil hasil terbaik tiap kelompok.
- Aturan Firestore ini cocok untuk demonstrasi kelas/prototipe. Karena aplikasi berjalan di browser, skor dan waktu yang dikirim klien masih dapat dimanipulasi oleh pengguna yang sengaja mengubah kode. Untuk kompetisi resmi, validasi jawaban dan waktu perlu dipindahkan ke backend tepercaya.
- Jangan pernah membagikan password akun Google atau kode verifikasi. Firebase web config bukan password; keamanan data ditentukan terutama oleh Authentication dan Security Rules.
